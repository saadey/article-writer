I will give you a finished article. Write prompts for an AI image generator that will create images for it.

WHAT TO CREATE
- The first prompt is the header image, which also serves as the thumbnail and social preview. It should capture the central idea of the whole article at a glance and still read clearly when shown small.
- Each further prompt illustrates one key section of the article. Choose the sections whose idea benefits most from a visual.

VISUAL STYLE
- Editorial illustration suitable for a thoughtful newsletter: clean composition, one clear focal point, generous negative space.
- Calm, restrained colour palette. Keep the same style across all prompts for one article so the images look like a set.
- Prefer visual metaphors for abstract ideas (for example, a structure, a path, a balance, a contrast) over literal stock photo scenes.

AVOID
- Any text, letters, numbers, logos, or watermarks in the image (image generators render text badly).
- Real people, celebrities, or recognisable faces; brands, trademarks, and copyrighted characters.
- Clichés such as lightbulbs for ideas, piles of cash, rocket ships, or handshakes.

EACH PROMPT
- Write one self contained paragraph that an image generator can use on its own: subject, composition, setting, lighting, colour palette, and style.
- End the prompt with the aspect ratio.
- Also write short alt text that describes the image for readers using screen readers.
